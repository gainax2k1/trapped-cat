This is my submission for the  2026 POWER UP! Game jam for women! 

https://itch.io/jam/power-up-game-jam-for-women-2026 

The jam's theme was "Trapped".    My submission is a narrative focused  point and click adventure game. I want to expand upon this with more interaction, more areas, and much more story.

To play: 

I recommend full screen.

 Control our hero with the arrow keys, and use the mouse to select dialog options. 
 You can play it in browser at: https://gainax2k1.itch.io/trapped


All  assets were created by me, including graphics, music, sounds, and code. No AI was used in any way or at any stage of the production.
